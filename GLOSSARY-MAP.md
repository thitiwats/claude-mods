# Glossary Map

## Contexts

- [handoff-nudge](./plugins/handoff-nudge/GLOSSARY.md): nudges a long conversation toward `/handoff` and offers to resume a handoff in a fresh one
- [prompt-upgrade](./plugins/prompt-upgrade/GLOSSARY.md): turns a prompt into an upgraded one with the same intent, asking clarifying questions first
